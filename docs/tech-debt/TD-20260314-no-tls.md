# TD-20260314-no-tls

- **ID**: TD-20260314-no-tls
- **Area**: Infra (Docker gateway, desktop/native server)
- **Problem (fact)**: Kronn serves plain HTTP. The Docker gateway listens on
  port 80 only, with no TLS server block. `[src: file: .docker/nginx.conf:5]`
- **Why we can't fix now (constraint)**: certificates for a local-first app
  (self-signed trust, renewal, desktop bundles) need a plan of their own.
  Tailscale encrypts peer-to-peer traffic in the meantime.
- **Impact**: security when the backend is exposed beyond loopback.
- **Where (pointers)**: `.docker/nginx.conf`, `server.auth_strict_localhost`
  (a Bearer token even on loopback). `[src: file: backend/src/models/setup.rs:115]`
- **Suggested direction (non-binding)**: nginx-fronted TLS first, then flip
  the default of `auth_strict_localhost`, as described in
  `docs/operations/auth-and-tls.md`.
- **Next step**: create ticket.
