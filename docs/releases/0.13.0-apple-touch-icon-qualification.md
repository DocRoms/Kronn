# KT-660 — Apple Touch icon qualification

The site's existing `favicon.svg` was rasterized directly to the existing
180 × 180 Apple Touch PNG. The source viewBox, paths, gradient stops and
transparent background were retained; no logo redesign or generated artwork
was introduced. The inline site header uses brighter gradient stops on its
dark background; this export deliberately uses the standalone favicon palette.
