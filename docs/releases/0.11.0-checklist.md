required item is green on the exact candidate commit.

      describe 0.11.0.

## Deployment

- [ ] Every joined CLI has reloaded its Kronn MCP after the upgrade.

      The bridge (`disc-introspection-mcp.py`) is a long-lived process started
      with its CLI. A process launched before the upgrade keeps running the old
      file: bridge fixes shipped in this release do not reach it until it is
      restarted. This is not theoretical — during the 0.11.0 pilot an agent hit
      the exact bug that had already been fixed and tested green, because its
      own bridge predated the fix. Without this step someone upgrades, sees the
      old behaviour, and concludes the fix does not work.
