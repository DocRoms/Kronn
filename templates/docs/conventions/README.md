# Conventions

> **Seeded by the audit** from the Git workflow the team stated in the briefing (`git-workflow.md`), when it did; empty otherwise. It then fills up one file at a time, as agents and humans meet project-specific conventions while doing real work.

## What goes here
Project-specific conventions — naming patterns, idioms agents must follow, micro-rules that don't fit `coding-rules.md` (one level up).

One file per topic, e.g. `pnpm-vs-npm.md`, `git-signoff.md`, `commit-style.md`.

Curated by humans + agents. Cross-ref with `[[wikilinks]]` for Obsidian graph.
