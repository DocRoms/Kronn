# Gotchas

> **Seeded by the audit** from the traps the team listed in the briefing (`known-traps.md`), when it did; empty otherwise. It then fills up as agents (and humans) hit footguns during real work.

## What goes here
Sharp edges to know before touching code — runtime quirks, footguns, version-specific issues, MCP integration weirdness, framework bugs.

One file per topic, e.g. `jira-mcp-escapes-panels.md`, `migration-locks-table.md`.
