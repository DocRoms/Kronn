# RE-VERIFICATION MODE (preserve existing documentation)
Read the existing content in `{target}` and every other document this step may touch. Use the step below as a checklist; add missing content without replacing what remains accurate.
1. Check every fact and every `[src: …]` citation against the current code: open the cited file at the cited line.
2. Correct what is false or stale (moved line, renamed or deleted file, changed command or version), add what the checklist requires and the file lacks, remove what no longer exists.
3. Keep every statement that is still true exactly as written: no rephrasing, reordering or restyling.
4. In a section marked `owner="human"`, correct only what the code contradicts: its owner reconfirms the change.
5. If everything is still accurate, leave the file byte-identical: the step then ends unchanged, a valid result.
